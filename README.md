This is a very simple toolkit

for Python CLI programs. There are better options

out there, but this is just a simple hobby project.

# how to use

At the very top of your

Python program:

```python
from cck.py import *
```

Then clone this GitHub repo, and take **cck.py**.

Next add it to the same folder as the Python file you want to use it in.

The rest of the files you don't need.

**tools:**

1. clear() - Clears all text in the terminal.

2. wait(wait_time) - Waits however many seconds you put.

3. menu_one("menu_text") - Puts a basic menu in the terminal with customizable text.

4. menu_two("menu_text", "menu_text_two") - Puts a basic menu in the terminal with two lines of customizable text text.

5. menu_three("menu_text, "menu_text_op1"-"menu_text_op4") - Puts a basic menu in the terminal with a header, and 4 lines of customizable text.

6. sysinfo() - Prints some basic info about the system CCK is running on.
